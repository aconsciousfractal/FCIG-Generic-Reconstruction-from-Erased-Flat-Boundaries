## Candidate scope

The manuscript proves conditional exact reconstruction for three-dimensional
proper-zero reflected-cap data using the intrinsic boundary-germ skeleton, a
fixed-realization measure-zero statement for excluded centres, hinge-anchored
unconditional uniqueness, a five-differing-sites-per-side exchange bound
resting on a computer-assisted nonexistence theorem with archived verified
certificates, and unconditional uniqueness for data with at most four hidden
facets. The public code implements the exact steps-4-to-6 flat kernel with
the two-condition certifier, the exceptional-centre and reversed witness
families, the certificate verification, and their frozen rational replays —
not the complete input-extraction pipeline.
